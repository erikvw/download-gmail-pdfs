Gmail App passwords
-------------------

Here's how to create an app password in gmail:

* Turn on 2-Step Verification. App Passwords only appear once it's on.
* Go to https://myaccount.google.com/security
* Under "How you sign in to Google," click 2-Step Verification and follow the setup prompts.
* Open the App Passwords page.
* Go directly to https://myaccount.google.com/apppasswords. The link is buried in the menus, so the direct URL is easiest. You can also search for App Password.
* Sign in again if asked.
* Create the password.
* Enter a name you'll recognize later, for example download-gmail-pdfs.
* Click Create.
* Copy the password (A dialog shows the 16-character code in the format xxxx xxxx xxxx xxxx). Copy it now, because Google won't show it again.

If the App Passwords page says "not available":

* 2-Step Verification isn't fully on yet.
* It's a Google Workspace account (work or school) and the admin has disabled App Passwords.
* The account uses only security keys with Advanced Protection.

Enable IMAP in Gmail. Fetching mail needs this.

* In Gmail, go to ⚙️ Settings → See all settings → Forwarding and POP/IMAP.
* Set IMAP access to Enable, then click Save Changes. Newer accounts may already have IMAP on with no toggle shown.
